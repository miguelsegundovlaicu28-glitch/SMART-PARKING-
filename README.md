# SMART-PARKING-
Proyecto Backend programado en Java . Trata de una aplicación que gestiona de forma optimizada las reservas de parking: en ella se podrá crear una ciudad dividida por zonas que permitan la gestión de las reservas, cancelaciones y pagos de varias plazas de aparcamiento.
Se podrá consultar las plazas disponibles en cada momento en cada zona y reservarlas con un mínimo de antelación. La cancelación en caso de hacerse las ultimas 24 horas de la fecha de reserva se impondrá una penalización.
Aparte se notificará cuando haya un hueco disponible al cliente en la zona deseada en caso de que no haya, si lo prefiere también la aplicación en caso de que una plaza concreta no esté disponible propondrá al cliente una plaza de la misma zona o la más cercana posible teniendo en cuenta el precio y la distancia a la plaza deseada.
Se adjunta programa con test.
